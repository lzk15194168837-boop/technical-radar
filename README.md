# 技术雷达｜知识卡界面交接包

版本 v0.6-handoff.1 · 2026-10-22。先体验阅读交互，再查看小程序界面源码。

## 下载后怎么打开

1. GitHub绿色 Code → Download ZIP，解压整个包。
2. 双击根目录 start.html，在浏览器查看离线演示。无需微信登录、安装依赖或云服务。
3. 左右拖动/滑动、方向键或前后按钮翻卡；支持类型筛选、搜索、目录与详情。
4. 查看源码和真实接入条件，请读 docs/HANDOFF.md。

GitHub源码页面不会直接运行HTML；请下载解压后打开。本仓库没有部署在线网站或正式微信体验版。

## 产品要解决什么

把日常遇到的AI工具、软件和组合做法，整理成知道用途、能判断是否值得花时间、以后找得到的知识卡。
能力、可靠、个人适用、组合替代价值分别判断，不用一个总分掩盖差异。详细理由、来源、风险和历史按需查看。

## 包含什么

- start.html：零依赖浏览器演示。
- miniprogram/：从现有v0.6页面提取的原生界面源码，改接离线示例。
- project.config.json：微信开发者工具项目配置，touristappid为占位，仅供本地模拟器尝试。
- demo/catalog.json：3条明确虚构的示例，评分不是对真实工具的评测。
- docs/HANDOFF.md：工程结构、改动、已做与未做、接入步骤。
- docs/FOR_REN.md：可直接转发给任哥的介绍。

## 交付边界

这是阶段性的界面源码与交互演示，不是完整自动研究系统。
没有真实个人知识、个人画像、账号凭据、云环境、电脑控制/截图、后台Agent或S1/R1源码。
不会连接原作者的设备或云端。演示中的提交仅保存到当前设备，不会传电脑。
真实部署需接收者自己的AppID、数据、后端和身份校验，研究能力需另行取得和核验。
GitHub下载不等于能直接在微信扫码运行。
